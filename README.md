# 🏋️‍♂️ DevGym — Seu Ginásio de Programação Gratuito

O **DevGym** é uma plataforma comunitária e 100% gratuita desenvolvida para pessoas que querem aprender e praticar HTML profissional por meio de desafios de código em tempo real. O projeto conta com um sistema de etapas automatizado e um tutor de Inteligência Artificial integrado para guiar o aprendizado.
---
## ✨ Funcionalidades Principais

*   **🔒 Tela de Login Moderna:** Interface elegante com efeitos de transição nos botões e validação visual de campos.
*   **🎯 Validação por Etapas (Steps):** Conforme você digita o código no editor, a plataforma valida as regras em tempo real e marca as missões concluídas com um ✔️ verde.
*   **🤖 DevAI (Tutor Integrado):** Um assistente de IA simulado que analisa erros de sintaxe e dá dicas profissionais contextuais para cada desafio sem entregar a resposta pronta.
*   **🏆 Certificado de Conclusão:** Ao atingir 100% de progresso, um modal interativo celebra a conquista do estudante com as informações de autenticação da trilha.
*   **📱 Design Responsivo:** Todo o sistema foi pensado e adaptado tanto para telas de computadores quanto para dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído puramente com tecnologias web nativas, focado em semântica e boas práticas de mercado:

*   **HTML5:** Estruturação semântica de formulários, inputs, caixas de workspace e acessibilidade.
*   **CSS3:** Layouts baseados em **Flexbox** e **CSS Grid**, variáveis de cores modernas (estilo Tailwind/VS Code) e animações de clique.
*   **JavaScript (ES6):** Manipulação dinâmica do DOM, motor de testes regex em tempo real e lógica de respostas do assistente DevAI.

---

## 💻 Como rodar o projeto localmente

Se quiser baixar este projeto para estudar ou fazer modificações no seu computador, basta seguir os passos:

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd devgym
   ```
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência!
